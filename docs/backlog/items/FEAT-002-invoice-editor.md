# FEAT-002 — Invoice editor with live preview and print

**What.** A split-screen editor — header, customer and line-item grid on the left, a live document preview on the right — with Draft/Sent/Paid/Overdue/Cancelled status, auto-numbering, live totals, and print-to-PDF via a @media print stylesheet.

**Why now.** Invoicing is the one thing in EP-01 that Wallet cannot express today. If only one item from this epic is ever built, it is this one.

**Out of scope.** Recurring invoices, payment reconciliation, emailing.
